## v0.2.0 — a(4), N = 5 level 3, jet evaluation, external review

Second tagged release. Since v0.1.0 (22 Apr 2026, 69 commits) the project
gained its next headline term, a new evaluation engine that made it
cheap, an exact N = 5 level-3 result, one engine bug fix, and an external
review of the whole repository. This release also corrects several
statements in the v0.1.0 notes that are now known to be wrong (see
**Errata** below).

### Headline results

- **a(4) = 5,914** for the planar 3-body problem, extending the OEIS
  A395423 sequence to `[3, 6, 17, 116, 5914]`. Computed by jet evaluation
  mod p over the full corrected 11,937-bracket level-4 census
  (2026-07-29/30), doubly verified at independent (prime, seed) pairs,
  re-verified through the `poisson-algebra` library (2026-09-30), and
  reproduced by an independent third method in the external review.
  **Epistemic status:** certified lower bound `d(4) ≥ 5,914`; equality
  holds up to Schwartz–Zippel probability (~1e-4 per run), the same rung
  as L3(5) below. The exact-ℚ upper bound is still open.
- **a(4) is potential-universal one level further:** 1/r, 1/r² and 1/r³
  all give 5,914.
- **N = 5, level 3: L3(5) = 5,965** (1D, 1/r), triply verified
  (two prime/seed sampling runs + exact mod-p streaming elimination).
  This **falsifies** the `new_L3 = 1198·C(N,4)` extrapolation
  (predicted 6,135). Current zero-degree-of-freedom fit predicts
  L3(6) = 17,979 (untested).
- **N = 10, level 2: L2(10) = 1,565**, exact over ℚ, confirming the
  registered prediction `L2(N) = N(4N² − 9N + 3)/2` out of sample.
- **OEIS A395423 approved and published** (2026-07-29): `3, 6, 17, 116`,
  keywords `nonn, hard, more`.

### New engine

- `jet_eval/`: truncated multivariate Taylor jets over F_p, vectorised
  across sample points. Evaluates nested-bracket trees without building
  symbolic expressions. Validated 3/3 against known values
  (`[3,6,17,116]`, `[10,25,145]`, `[6,14,62,1260]`); N = 4 level 3 in
  92 s on a desktop versus 52 min on a 31-worker AWS instance for the
  symbolic engine. Design memo: `docs/jet_eval_design.md`.
- `jet_eval/run_basis_census.py`: basis-reduced census. Brackets are
  formed only from a maximal independent subset of each level (exact by
  bilinearity), cutting N = 6 level 3 from 25.6M candidate trees to
  ~38K; lean uint32 rank kernel and split eval/rank stages via value
  checkpoints. Same mod-p epistemics as `run_l4.py`. Validated 5/5 against known level ranks, including L3(5) = 5,965 in
  225 s on a desktop. Results: `results/jet_eval/basis_census/`.

### Bug fix

- **Hidden zeros after the `cancel` → `together` swap** (`803310b`,
  2026-09-30). `together` can leave a mathematically-zero bracket
  structurally nonzero; per-column SVD normalisation then turned its
  float cancellation noise into phantom rank (harmonic N = 3, d = 2,
  level 4 reported 34 instead of closing at 15; 344 of 11,937 brackets).
  `simplify_generator` now applies an exact Schwartz–Zippel zero test and
  returns literal 0. Regression test added. Exact-ℚ and mod-p headline
  numbers were never affected; any pre-fix float64 run with many
  vanishing brackets could be.

### External review (unreviewed — read the label)

`docs/pending_review/2026-09/` contains an independent evaluation of the
repository made in Sept–Nov 2026: a claim-by-claim ledger of everything
the project asserts with status (proven / lower bound / evidence /
refuted) and evidence paths; exact (mod p and over ℚ) verification
scripts; and a literature check. **Nothing in that folder has been
accepted into the project.** It is shipped because it is already on
`main` and because its scripts reproduce the headline numbers
independently. Its main findings, for orientation only:

- `[3, 6, 17, 116]` is certified for the actual phase-space functions
  (u = 1/r enforced), closing the gap between the formal rank and the
  float SVD.
- Through level 3 the algebra is the free Lie algebra on three
  generators (`3, 6, 17, 119`) minus exactly one relation at bracket
  length 4; the relation appears to be the classical identity
  `{V,{V,{V,T}}} = 0` filtered by locality, not a property of 1/r.
- The per-bracket-length dimensions `3, 3, 8, 17, 44, 103, 272, 572`
  (1D) are absent from OEIS and the literature; the closest work is
  McLachlan & Murua, *The Lie algebra of classical mechanics* (2019),
  which treats the two-piece T + V case.
- 1D level 4 gives a lower bound of 5,042, versus 5,914 planar; whether
  the two truly differ awaits an exact upper bound.
- The "super-exponential / infinite Gelfand–Kirillov dimension" framing
  of paper 1 is argued to be wrong (GK dimension is bounded by a degree
  count); atlas "rank drops" are float conditioning, not algebra.

### Errata to the v0.1.0 release notes

- `d(4) ≥ 5,604` → **`d(4) ≥ 5,914`** (mod p, quadruply verified). The
  5,604 figure was a float64 SVD estimate with a non-definitive gap.
- "OEIS A395423 allocated, awaiting editor approval" → **approved and
  published 2026-07-29.**
- Yukawa listed among universal potentials: those runs used a 4-term
  Taylor truncation in `u`, i.e. a composite power potential, **not**
  `e^{−μr}/r`. An exact exponential run has not been done. (A pure
  `e^{−r}` potential, run exactly in 1D in the review, does give
  `[3, 6, 17, 116]`.)
- "Papers 1–5 are drafts": there are four papers; only paper 1 (the
  Zenodo deposit) has been through the author's own review. Papers 2–4
  are exploration notes in paper form.
